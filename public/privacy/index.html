PRIVACY

Your listening space should be clear about data.

Chai With Music is currently ad-free. This page explains the main website technologies used by the site and should be updated whenever those practices change.

Advertising

Chai With Music is currently ad-free. No Monetag advertising code is intentionally included in the current website experience.

Analytics

The website can use analytics when the site owner enables a valid measurement ID. Analytics events are intended to understand visits and interactions such as referrals and sharing.

Sharing

If you use the share controls, the site can open the sharing service you select or copy a link to your clipboard. The selected third-party service handles the share action under its own privacy policy.

Changes

This page will be updated when the website introduces new analytics, advertising, account features or other data collection.
