# Chai With Music

Chai With Music is a calm web listening experience built around lo-fi music, study music, focus music and Indian chai ambience.

**Live:** https://chaiwithmusic.vercel.app/

## What it is

- Lo-fi and background music for studying, reading and work
- Focus-oriented listening for coding and concentration
- Indian tea-stall and chai ambience
- A quiet, browser-based experience with no advertising
- Practical guides for using background music during study and focused work

## Promotion and sharing

The official promotion page contains a short description, category suggestions, the best topic-specific URLs and guidance for publishers and communities:
https://chaiwithmusic.vercel.app/promote/

When sharing Chai With Music, link to the page that best matches the audience (for example, Study Music for students or Focus Music for developers) rather than repeatedly posting only the homepage. Avoid automated, paid or bulk backlink schemes.

## Development

This project uses Vite, React, TypeScript and Tailwind CSS.

Run locally:

```bash
npm install
npm run dev
```
